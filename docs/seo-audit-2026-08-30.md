# TCS Website & SEO Audit

**Date:** August 30, 2026

## Business and search scope

- Primary offer: commercial kitchen ventilation diagnostics and repair.
- Primary market: New York City's five boroughs.
- Secondary market: selected Northern and Central New Jersey locations.
- Supporting capabilities may be described accurately, but broad residential HVAC, hood cleaning, fire suppression, response-time guarantees, and unsupported manufacturer-authorization claims are outside the promoted scope.

## Baseline findings

- The live sitemap listed 62 URLs, while the production build generated 77 pages.
- Ten cities had both a `/locations/` page and a richer kitchen-ventilation city page competing for the same local intent.
- A legacy dynamic service/city route produced thin pages for broad equipment categories and contained claims that were not supportable as public marketing copy.
- The blog and sitemap mixed the current ventilation focus with older, broad equipment-repair topics.
- Several public descriptions used absolute, speed, certification, authorization, or coverage language that needed qualification or removal.
- Google Ads tracking existed, but GA4 click-to-call and lead events and Search Console verification were not configurable.
- The Resources page linked to a retired NYC DEP URL.
- The Resources and energy-calculator pages were missing canonical metadata.

## Changes implemented

- Consolidated duplicate city URLs with permanent redirects to the stronger kitchen-ventilation landing pages.
- Retired the legacy service/city template and redirected those URLs to their base capability pages.
- Limited the XML sitemap to 44 intentional, indexable URLs.
- Kept nine focused ventilation articles indexable; older articles remain accessible but are marked `noindex, follow` and excluded from the sitemap.
- Repositioned vertical pages around commercial kitchen ventilation and narrowed internal service links to the supported focus.
- Rewrote service, location, vertical, and article claims to match current operating scope.
- Added concise titles, meta descriptions, and missing canonicals.
- Added optional GA4 configuration, `click_to_call`, and successful `generate_lead` events without removing existing Google Ads conversions.
- Added optional Google Search Console verification metadata.
- Replaced the retired NYC DEP resource with the current official building, construction, and emissions page.
- Added `npm run seo:audit`, an automated sitemap crawl that checks status, title, description, canonical, robots, and H1 output.
- Replaced the outdated 30-day plan with a focused operating plan and publishing guardrails.

## Validation

- `npm run build`: passed, including Next.js type checks; 67 pages generated.
- `npm run seo:audit -- --base=http://127.0.0.1:3100`: 44 URLs checked, 0 errors, 0 warnings.
- Representative duplicate location and legacy service/city URLs return permanent redirects to their intended destinations.
- `git diff --check`: clean.
